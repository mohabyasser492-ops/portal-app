# Security Baseline

- OAuth Authorization Code Flow with PKCE.
- No secrets in mobile or Git.
- Platform secure storage for tokens.
- API token validation and resource authorization.
- Least-privilege Graph permissions.
- HTTPS only, rate limits, correlation, safe errors.
- Privacy-safe logs, analytics, crash reports, and push payloads.
- File validation and scanning.
- Environment isolation and approved secret management.
