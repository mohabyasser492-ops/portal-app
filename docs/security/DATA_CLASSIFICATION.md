# Data Classification

- Public: approved general announcements.
- Internal: service catalog and general company content.
- Confidential: employee profile, requests, balances, attendance, approvals.
- Highly confidential: payroll documents, incident details, tokens, credentials.

Highly confidential data is not stored offline or included in telemetry/push payloads without explicit approval.
