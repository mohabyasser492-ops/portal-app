# Mobile Storage Policy

Tokens use platform secure storage. Approved summaries and drafts use Drift. Cache entries require classification, expiry, owner, clear-on-logout decision, and migration tests. Payroll documents, incident details, tokens, and confidential attachments are not persistently cached by default.
