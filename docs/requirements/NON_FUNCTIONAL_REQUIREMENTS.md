# Portal App Non-Functional Requirements


> Product: Portal App  
> Status: Implementation baseline  
> Version: 0.1  
> Last reviewed: 2026-08-24  
> Technical owner: Backend, Integration & Platform Engineer  
> Mobile reviewer: Mobile UI/UX & Product Experience Engineer  
> Security/Architecture approval: TBD

- **NFR-001**: Shared Flutter codebase for Android and iOS.
- **NFR-002**: Consistent Arabic RTL behavior.
- **NFR-003**: PKCE, no mobile secrets, least privilege, and API authorization.
- **NFR-004**: Sensitive data excluded from logs, analytics, notifications, and crash reports.
- **NFR-005**: Accessible status using text and icon, not color alone.
- **NFR-006**: Safe cache, network handling, retry, and duplicate prevention.
- **NFR-007**: API hides enterprise implementation details.
- **NFR-008**: Monitoring, correlation, audit, and safe failures.
- **NFR-009**: Maintainable clean architecture and automated tests.
- **NFR-010**: Isolated configuration and controlled releases.
