# Portal App Screen Requirements


> Product: Portal App  
> Status: Implementation baseline  
> Version: 0.1  
> Last reviewed: 2026-08-24  
> Technical owner: Backend, Integration & Platform Engineer  
> Mobile reviewer: Mobile UI/UX & Product Experience Engineer  
> Security/Architecture approval: TBD


Every applicable screen supports loading, populated, empty, error, offline, accessibility, and RTL states.

- Login: branding, Microsoft sign-in, privacy, version, errors.
- Home: greeting, summary, quick actions, pending requests, balance, announcement, news, safety.
- My Requests: filters, list, draft/pending/approved/rejected/cancelled statuses.
- Request Form: type-specific fields, draft, attachments, validation, submit.
- Request Details: data, status text/icon, timeline, eligible actions.
- Services: search, categories, availability, external-link warnings.
- News: feed, details, metadata, read state, attachments.
- Profile: basic, employment, contact, shift, security, masking.
- Manager Approvals: inbox, details, timeline, approve/reject and reason.
- Incident Reporting: type, time, location, description, attachments, tracking.
- Notifications: safe summaries, read state, deep links, preferences.
- Settings: language, privacy, version, notification preferences, logout.
